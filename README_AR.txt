ملفات نشر تطبيق أرقامي العربية على GitHub Pages

1) أنشئ مستودعاً جديداً على GitHub، مثلاً arqami-arabic.
2) ارفع index.html إلى جذر المستودع (وليس داخل مجلد فرعي).
3) افتح Settings ثم Pages.
4) ضمن Build and deployment اختر Deploy from a branch.
5) اختر الفرع main والمجلد /(root)، ثم Save.
6) انتظر دقيقة أو دقيقتين، وسيظهر رابط الموقع في صفحة Pages.

سيكون الرابط غالباً:
https://USERNAME.github.io/REPOSITORY/

استبدل USERNAME باسم حسابك وREPOSITORY باسم المستودع.
